# Mabinogi Mobile Task Assistant

Vue 3 + Vite + Tailwind CSS SPA for tracking multi-character daily/weekly tasks in Mabinogi Mobile.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Multi-character task lists with localStorage persistence (`mabinogi_tasks_multi`)
- Daily (06:00) and weekly (Monday 06:00) auto-reset countdowns
- Pinned tasks, count targets, category filters
- Character progress overview modal
- JSON export / import
